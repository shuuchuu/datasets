# Python exercises

Small text files used by the exercises of shuuchuu's Python courses (files, regular
expressions).

## Files

- `notes.txt`: one (made-up) student grade per line.
- `cigale-fourmi.txt`: Jean de La Fontaine's fable *La Cigale et la Fourmi*, with
  irregular spacing added on purpose (regex exercise).
- `fichier-a-dehtmliser.html`: a small HTML page whose tags must be removed (regex
  exercise).
- `breves-doublons.txt`: short humorous sayings with repeated words added on purpose
  (regex exercise).

## Source

Written for shuuchuu's Python course, originally in
https://github.com/shuuchuu/langage-python (`data/`).
