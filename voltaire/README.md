# Voltaire

French text of 10 works by Voltaire.

## Files

- One file per work: `Candide.txt`, `histoiredesvoyagesdescarmentado.txt`,
  `jeannotetcolin.txt`, `lamortdecesar.txt`, `leblancetlenoir.txt`,
  `lemondecommeilva-visiondebabouc.txt`, `lingenu.txt`, `micromegas.txt`,
  `traitesurlatolerance.txt`, `zadig.txt`.
- `concat_voltaire.txt`: all the works, concatenated.
- `voltaire_clean.txt`: all the works on a single line, line breaks removed, for
  character-level text generation.

## Source

Most likely Project Gutenberg's French eBooks (https://www.gutenberg.org), stripped of
their header and license.
