# Wikipedia Movie Plots

Plot descriptions of 34,886 movies from around the world, scraped from Wikipedia.

## Files

- `wiki_movie_plots_deduped.csv`: one movie per row, with the columns `Release Year`,
  `Title`, `Origin/Ethnicity`, `Director`, `Cast`, `Genre`, `Wiki Page` (the Wikipedia
  page the plot comes from) and `Plot`.

## Source

Kaggle, by Justin R.: https://www.kaggle.com/datasets/jrobischon/wikipedia-movie-plots
