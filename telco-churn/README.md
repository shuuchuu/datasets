# Telco Customer Churn Dataset

7,043 fictional customers of a telecom operator: demographics, subscribed services,
contract, billing, and whether they left last month (`Churn`).

`telco-churn.csv` is the original `data/Telco-Customer-Churn.csv`, unmodified.
