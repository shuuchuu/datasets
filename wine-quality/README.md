# Wine Quality (red)

Physicochemical measurements of 1,599 red Portuguese "Vinho Verde" wines, with a
quality grade (0–10) given by experts.

## Files

- `wineQualityReds.csv`: 11 physicochemical columns and `quality`; the first, unnamed
  column is a row number.
- `wineQualityInfo.txt`: the dataset's original description and citation request.

## Source

- UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/186/wine+quality
  (only the red wines are included here).
- Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). Wine Quality
  [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C56S3T
- Paper: P. Cortez et al., "Modeling wine preferences by data mining from
  physicochemical properties", *Decision Support Systems*, 47(4):547-553, 2009.
