# Fraudulent E-mail Corpus

More than 2,500 "Nigerian" (419) fraud e-mails, from 1998 to 2007, with their headers.

## Files

- `fradulent_emails.txt`: every e-mail, one after the other, each starting with a
  `From r ...` line.
- `debug_file.txt`: a small extract of it, to try code on.

## Source

- Kaggle, by Rachael Tatman: https://www.kaggle.com/datasets/rtatman/fraudulent-email-corpus
- Original: Radev, D. (2008), *CLAIR collection of fraud email*, ACL Data and Code
  Repository, ADCR2008T001.
