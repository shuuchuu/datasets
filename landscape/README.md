# Landscape (Intel Image Classification)

About 25,000 150×150 pictures of natural scenes, in 6 classes: `buildings`, `forest`,
`glacier`, `mountain`, `sea`, `street`.

## Files

- `seg_train/<class>/`: about 14,000 labeled training images.
- `seg_test/<class>/`: about 3,000 labeled test images.
- `seg_pred/`: about 7,000 unlabeled images.

## Source

- Kaggle: https://www.kaggle.com/datasets/puneet6060/intel-image-classification
- Originally published by Intel for an image classification challenge on
  https://datahack.analyticsvidhya.com
