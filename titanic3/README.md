# Titanic (titanic3)

1,309 passengers of the Titanic (no crew) and whether they survived: the full
`titanic3` dataset, with the `boat`, `body` and `home.dest` columns Kaggle's version
lacks.

## Files

- `titanic3.csv`: columns `pclass`, `survived`, `name`, `sex`, `age`, `sibsp`, `parch`,
  `ticket`, `fare`, `cabin`, `embarked`, `boat`, `body`, `home.dest`. Missing values
  are written `?` (as exported by OpenML).

## Source

- OpenML dataset 40945: https://www.openml.org/d/40945 (file
  https://www.openml.org/data/get_csv/16826755/phpMYEkMl)
