# Titanic (Kaggle)

Passengers of the Titanic and whether they survived, as split for Kaggle's *Titanic -
Machine Learning from Disaster* competition.

## Files

- `train.csv`: 891 passengers, with `Survived`.
- `test.csv`: 418 passengers, without `Survived`.
- `gender_submission.csv`: example submission (every woman survives).
- `data_description.txt`: description of the columns (in French).

## Source

Kaggle competition: https://www.kaggle.com/c/titanic
