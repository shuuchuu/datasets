# Bike Sharing

Hourly and daily bike rental counts of Washington D.C.'s Capital Bikeshare system in 2011
and 2012, with the weather and the calendar (season, holiday, working day).

## Files

- `hour.csv`: 17,379 hours.
- `day.csv`: 731 days.
- `Readme.txt`: the dataset's original description (columns, citation).

## Source

- UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
  (`bike+sharing+dataset.zip`, extracted)
- Fanaee-T, H. (2013). Bike Sharing [Dataset]. UCI Machine Learning Repository.
  https://doi.org/10.24432/C5W894
