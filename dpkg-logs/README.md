# dpkg logs

Real `dpkg` logs (package installs, upgrades and removals) from an Ubuntu 20.10 machine,
from October 2020 to April 2021, as found in `/var/log`, rotated files included.

## Files

- `logs.tar.xz`: extracts to `logs/dpkg.log`, `logs/dpkg.log.1` and
  `logs/dpkg.log.{2,3,4}.gz`.

## Source

Recorded on one of the trainers' machines for shuuchuu's Python system administration
course.
